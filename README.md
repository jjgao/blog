# jjgao/blog

A simple GitHub Pages blog scaffold.

## What lives here

- `_posts/` — dated blog posts
- `_layouts/` — page and post templates
- `assets/` — styles and images
- `about.md` / `archive.md` — static pages

## Local preview

This repo is set up to work as a GitHub Pages / Jekyll site.

```bash
bundle install
bundle exec jekyll serve
```

## Conventions

- Commits should use `jjgao <jianjiong.gao@gmail.com>`
- New posts go in `_posts/YYYY-MM-DD-title.md`
- Keep images in `assets/images/`
